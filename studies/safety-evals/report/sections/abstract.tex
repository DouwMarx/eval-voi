\begin{abstract}
Physical-AI safety evaluations need hardware, scenes and test time, so they look too expensive to pay off next to a question set for a large language model (LLM).
We test that intuition by pricing each evaluation by its expected value of sample information (EVSI) for one release decision, divided by what it costs to build and run.
Language models supply the eight parameters of this decision model for \voiNPhysical{} physical-AI and \voiNLLM{} LLM safety evaluations, and Monte Carlo draws carry their uncertainty.
At the central estimate a random physical-AI evaluation is worth more per dollar than a random LLM evaluation with probability only \voiEtaACentral{} (exact Mann-Whitney $p=\voiEtaMWp$). % CHECK-DATA
The cause is not cost or test quality, which are similar in the two groups, but the stakes: an LLM release decision carries about \voiStakesPerCostRatio{} times more at stake per evaluation dollar. % CHECK-DATA
The intuition is wrong about cost and right about value, and physical-AI evaluations would match LLM ones only at far larger deployments. % CHECK-DATA
\end{abstract}
